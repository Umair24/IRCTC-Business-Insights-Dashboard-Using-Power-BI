# IRCTC Business Insights Dashboard Using Power BI

## Project Overview

This project analyzes IRCTC railway booking data using Power BI to identify booking trends, revenue patterns, passenger demand, and train performance. The interactive dashboard helps users explore railway business data through visual reports and KPIs.

## Objectives

* Analyze railway booking and revenue trends.
* Monitor booking status, train occupancy, and delays.
* Explore passenger demand across train types and travel classes.
* Present key business insights through interactive visualizations.

## Tools & Technologies

* **Power BI**
* **Power Query**
* **Excel CSV Dataset**
* **Data Visualization and KPI Reporting**

## Key Features

* Interactive dashboard with KPIs and charts.
* Data filtering using slicers and filters.
* **Bookmarks** for interactive navigation and report views.
* **Report Page Tooltips** for additional contextual insights.
* Analysis of revenue, booking status, routes, occupancy, and delays.

## Dataset

The project uses railway booking data containing booking details, train information, travel classes, revenue-related fields, and operational performance metrics.

## Project Files

* `IRCTC Dashboard.pbix` — Power BI project file.
* `Dataset/` — Source dataset.
* `Screenshots/` — Dashboard previews.

## Key Learnings

* Building interactive Power BI dashboards.
* Analyzing structured datasets and identifying trends.
* Designing KPIs, bookmarks, and report page tooltips.
* Presenting business insights through data visualization.

## How to View the Project

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the dashboard using slicers, filters, bookmarks, and tooltips.
